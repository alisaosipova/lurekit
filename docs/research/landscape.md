# agent-attack-bench: research landscape

Status: Phase A deliverable, as of **2026-11-01**. Every external claim carries a URL. **UNVERIFIED** marks anything not confirmed in a primary source. Mechanisms are described at disclosure level only.

---

## 1. Summary

1. **No public artifact does 70% or more of what brief §1 plans.** The closest is **Promptfoo's `coding-agent:*` red-team plugins**, at about 50%. They cover harness and detection machinery (real-agent providers, canaries, trap host, protected-file hashes). They have no fixed corpus, no CVE or disclosure tracing, and no MCP or skill fixtures, and they depend on a remote generator (https://www.promptfoo.dev/docs/red-team/plugins/coding-agent/). Next are IssueTrojanBench (about 45%), MCPSecBench (about 35%) and Anthropic/Trajectory Labs (about 25%, not public).
2. **The defensible gap is narrower than brief §1 says.** The harness is not the novelty. The novelty is a **disclosure-traced, version-pinned corpus of inert fixtures, run offline against a user's own configuration, with published comparative results** (§6).
3. **Recommendation: narrow and merge, do not abandon** (§6.2). Build corpus and fixtures, keep the runner thin, import IssueTrojanBench payloads (CC BY 4.0), and split browser/SaaS scenarios into a separate track.
4. Attack catalog: **56 unique CONFIRMED or PARTIAL rows** (33 CONFIRMED, 23 PARTIAL). The 40-row bar is met **only if PARTIAL rows count**: fully CONFIRMED rows are **7 short** (33/40). In addition, **19 rows are browser/SaaS** and **2 are generic npm compromises**, which leaves **35 coding-agent or adjacent rows** (also below 40). 14 of those are patched, version-specific CVEs (regression tier).
5. All 20 seed items of brief §2.3 are in the CONFIRMED/PARTIAL table (mapping in §5.3). None was refuted. Several carry PARTIAL caveats (wrong primary URL, date or version drift, secondary-only fix status).
6. The brief's headline "vulnerable to 23 of 61 scenarios" is **not yet supported**. The deduplicated count applicable to Claude Code, Cursor, Codex and OpenHands is about 27, plus about 8 borderline.
7. Harness feasibility: Claude Code and Codex CLI can be driven headless with machine-readable tool-call streams. Cursor CLI headless works, but **IDE-only vectors (tasks.json folderOpen, Mermaid render, case-insensitive FS) cannot run headless**, and hook firing under `agent -p` is UNVERIFIED. OpenHands headless is **forced always-approve**, so it adds little configuration signal.
8. Static skill and MCP scanners are measurably bypassable: SkillCloak reports >90% bypass across 8 scanners (https://arxiv.org/abs/2607.02357), and Trail of Bits bypassed 5 scanners (https://blog.trailofbits.com/2026/06/03/the-sorry-state-of-skill-distribution/). This supports a runtime-effect measurement.
9. A vendor contradiction motivates an independent instrument. Anthropic reports 0/720 attack successes in auto mode (72 Trajectory Labs scenarios × 10 runs, Claude Code v2.1.205; the post says results measure the models, not deployments) (https://claude.com/blog/auto-mode-default-in-claude-code). The CSA note reports Rehberger at 60–80% code execution against the same mode (https://labs.cloudsecurityalliance.org/research/csa-research-note-claude-code-opus5-automode-injection-20260/).

## 6. Gap statement (brief §2.4)

### 6.1 What no public artifact provides, as of 2026-11-01

No public artifact provides **all** of the following:

- **(a)** A fixed, versioned corpus where every scenario cites a public disclosure, CVE, paper or incident.
- **(b)** Execution against unmodified, version-pinned agent CLIs from at least two vendors, run headless.
- **(c)** The user's own configuration as the variable under test: managed, project and local settings, hooks, MCP servers, skills, permission mode.
- **(d)** Inert fixtures on the surfaces where real attacks happened: MCP tool description and result, SKILL.md and bundled scripts, project settings/hooks/MCP files, local-registry package install, issue and web content.
- **(e)** Deterministic effect detection (canary egress, file, command) paired with a benign-task utility check.
- **(f)** Fully offline reproducibility, with no vendor-hosted generator or judge.

Every artifact in §2–§3 fails at least two of these.

### 6.2 Narrow / merge / abandon

**Abandon: not supported.**
- No artifact reaches 70%.
- Friendly Fire (2026-07-08) and the auto-mode bypass show that current versions remain exploitable by disclosed attack classes.

**Narrow and merge (recommended):**

1. **Build corpus and fixtures; keep the runner thin.** Promptfoo already has canaries, trap hosts and tiered grading. Consider exporting scenarios so a Promptfoo `file://` provider can run them, while staying offline and vendor-neutral. Do not depend on Promptfoo: it uses a remote generator and is owned by OpenAI.
2. **Split tracks.** 0.1 = CA/CA+ (35 rows). The BR track (19 rows: no user-held config, mostly fixed server-side) and SC (2 rows) are deferred or kept separate.

   - *Regression* (R, 14 coding-agent CVEs: AAB-001, -003, -004, -005, -006, -007, -011, -012, -013, -015, -016, -023, -024, -035). These will likely pass on current versions.

4. **Cursor in 0.1 = CLI only.** Mark AAB-007, -009 and -015 as IDE-only and not run headless.
5. **Deprioritize OpenHands** after Claude Code and Codex. Headless always-approve leaves little configuration signal.
6. **Import, don't re-author, the issue surface.** Use IssueTrojanBench payloads (CC BY 4.0, https://zenodo.org/records/21402335) with attribution.

### 7.2 Method note (2026-11-01)

1. Five parallel sweeps (academic benchmarks, industry benchmarks and taxonomies, runtime tools, static tools and data, agent harness docs) using web search and primary-source fetch: GitHub/npm/PyPI APIs, vendor docs, arXiv, the MITRE CVE Services API, the ATLAS YAML.
2. Attack catalog built in four batches (seeds 1–5, 6–10, 11–15, 16–20, each extended with additional finds).
3. Each scenario was independently re-verified by a separate pass. That pass re-opened the primary source and issued a CONFIRMED or PARTIAL verdict with corrected URL, date, affected versions and fix status. The corrections are applied in §5.1.
4. One sweep (seeds 6–10) was **re-run after a VM crash**. Its results were re-verified in the same way.
5. A skeptical gap review searched specifically for artifacts covering ≥70% of the brief. It found Promptfoo coding-agent plugins, ADR-Bench and KavachBench, which Phase A had missed.
6. Limits:
   - NVD, openai.com, Radware and Koi pages were not fetchable; MITRE API, Wayback or secondary sources were used and marked as such.
   - Model/vendor claims are reported, not replicated.
   - No active testing of any agent was performed.
